# Student Data Search

## About the Project

This is a practice project created to improve my skills in JavaScript, HTML, CSS, and Git/GitHub.

I built a web page that displays student information in cards and includes a real-time search bar to find students by name.

## Technologies Used

- HTML5 – For creating the webpage structure.
- CSS3 – For styling and designing the student cards.
- JavaScript – For handling student data and implementing search functionality.
- Git & GitHub – For version control and project management.

## JavaScript Concepts Practiced

In this project, I practiced:

- **Arrays of Objects** – To store student information.
- **`map()`** – To display student data dynamically.
- **`filter()`** – To find students matching the search input.
- **DOM Manipulation** – To dynamically display and update student cards.
- **Event Listeners** – To make the search bar work in real time.

## Git & GitHub Skills Practiced

I also practiced the following Git and GitHub concepts:

- Creating a GitHub repository.
- Creating and editing a `README.md` file.
- Using Git commands to track project changes.
- Checking project status using `git status`.
- Staging files using `git add`.
- Saving changes using `git commit`.
- Uploading changes using `git push`.

## Features

- Displays student information in card format.
- Real-time student search by name.
- Shows matching student records as you type.
- Displays a message when no matching student is found.

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser (or use the Live Server extension).
4. Type a student's name in the search bar to test the search functionality.
